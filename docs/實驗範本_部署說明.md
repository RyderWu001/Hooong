# 實驗範本（通用化）部署說明

系統的「試驗組條件」不再寫死染整欄位，改由**實驗範本**定義。管理員可在「系統 → 實驗範本」新增、複製或停用範本。

## 升級既有資料庫（只新增，不刪除任何資料）

```bash
cd backend
npm run db:push            # 新增 ExperimentTemplate 資料表、Experiment.templateId、ExperimentGroup.conditions
npm run db:seed-templates  # 補齊內建範本：通用 / 食品 / 清潔劑 / 染整（可重複執行）
```

> `db:push` 會直接修改 `DATABASE_URL` 指向的資料庫，請先確認不是要保護的正式庫，或先備份。

## 舊資料相容

- 舊實驗的染整欄位仍保留在資料庫。內建「染整」範本的欄位代碼與舊欄位同名，
  讀取時若試驗組沒有 `conditions`，會自動用舊欄位補值；編輯儲存後即改存入 `conditions`。
- 沒有指定範本的實驗：若含舊染整資料則套用「染整」範本，否則套用「通用實驗」範本。

## 範本欄位格式

`fields` 為陣列，每個欄位：`key`、`label`、`type`（text / textarea / number / select / multiselect / date）、
可選 `unit`、`placeholder`、`options`、`section`（分組標題）、`showWhen`（`{ key, in }` 或 `{ key, notIn }`，依另一欄位的值決定是否顯示）。

## 已知限制

- 已被實驗使用的範本不能刪除，請改用「停用」。
- 修改既有範本的欄位代碼，會使已存資料不再顯示該欄位（資料本身仍在 `conditions` 中）。

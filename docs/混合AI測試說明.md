# Hooong 混合 AI 本機測試版

## 使用

開啟 http://localhost:5173/assistant，以管理員登入，選擇：

- 本地模型：保持原本的本機查詢。
- 遮蔽預覽（不傳送）：本機查詢後顯示可傳送的 JSON 摘要。
- 自動分流（本地＋雲端）：允許的單輪查詢使用雲端摘要；其他需求留在本機。

變更模式會清除目前畫面的對話。

## 第一版範圍

需求由固定規則或本機 Ollama 辨識，分類及工具參數都必須通過後端驗證。後端檢查使用者可查閱的工具；混合測試目前僅開放 ADMIN。

允許的雲端資料：
- 成本排行：隨機配方代號與排名，不含成本金額。
- 漲價影響：隨機配方代號、成本變動百分比、受影響筆數，不含成分、比例、單價與成本金額。
- 庫存／效期：隨機紀錄代號、缺口或剩餘量、單位、距到期天數，不含名称、批號與絕對日期。

原始問題、歷史對話、自由文字、姓名、客戶、真實名稱與代碼對照表不送往雲端。每次查詢產生不同代號；本機還原回答中的紀錄名稱。模型分類不會放寬欄位允許規則。

第一版的多輪對話、化學明細、修改／刪除／新增、未辨識需求都使用本機模型。不會執行 AI 資料寫入或修改資料庫架構。

## 雲端設定

在 /Users/wuyulai/Hooong/backend/.env 設定（勿將金鑰提交到 Git）：

```dotenv
AI_CLOUD_ENABLED=yes
AI_CLOUD_BASE_URL=https://api.openai.com/v1
AI_CLOUD_MODEL=gpt-4.1-mini
AI_CLOUD_API_KEY=填入你自己的API金鑰
```

修改後重啟後端，重新整理頁面。AI_CLOUD_ENABLED=no 可停用雲端，自動分流會顯示預覽。OpenAI 相容服務必須支援 Chat Completions 與 store:false；使用 HTTPS 端點。store:false 不等於供應商零資料保留，仍須核對供應商政策。

金鑰建立：https://platform.openai.com/api-keys
模型文件：https://developers.openai.com/api/docs/models/gpt-4.1-mini

## 驗證與限制

前後端編譯通過，52 項測試通過；新增測試涵蓋欄位投影、身分資訊遮蔽、代號隔離、權限、歷史對話、停用與錯誤處理。已用真實資料庫驗證成本與庫存遮蔽預覽，並確認雲端 API 連線。

這是可測試版本：未完整評估所有問法的分類正確率、多使用者負載或模型回答數值正確率。目前資料庫連線仍指向遠端，不是本機資料庫。

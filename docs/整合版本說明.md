# 通用實驗室整合版本

2026-10-11 整合來源：GitHub origin/master（15b3ca0）、通用化 refactor/generic-lab（46a7ed8）、Downloads/master（cb505d9）及 Downloads 四項未提交修改。

包含獨立 AI 助理、知識庫 AI 問答、動態實驗條件與四種內建範本，保留配方、原料、庫存、風險、實驗、樣品、結果、報表、供應商、表單與簽核及系統管理。原料與風險管理恢復選單入口。

## 本機啟動

- backend：`npm ci`，設定自己的 `.env`，執行 `npm run dev`（3000）。安裝時自動產生 Prisma client。
- frontend：`npm ci`，`npm run dev`（5173）。
- AI：啟動 Ollama，準備 `qwen2.5:7b`；可透過 `OLLAMA_BASE_URL` 與 `OLLAMA_MODEL` 調整，`AI_DISABLED=yes` 可停用。

## 既有資料庫升級

本次連接的資料庫已套用 `backend/prisma/upgrade-generic-lab.sql`，並執行 `npm run db:seed-templates`。SQL 只新增範本資料表、欄位、索引與關聯，保留既有紀錄。此 SQL 供尚未升級的資料庫使用，請勿重複執行；升級前先核對資料庫結構與連線目的地。

# 歷史實驗參考及結果摘要

AI 助理「操作」新增「參考過往實驗」與「結果摘要與比較」。登入者必須同時有 experiments.view 與 results.view；API 與選單均驗證權限。所有資料只在現有後端及本機 Ollama 處理，不增加雲端揭露範圍、不更動資料庫結構、不自動寫回原始紀錄。

## 歷史參考

輸入產品、目的或條件；可選擇參照實驗。依中文字詞／字串命中、相同範本及配方關聯排序，最多檢索200筆近期候選，取前6筆。這是可解釋的文字檢索，尚未使用向量語意檢索，也不代表測量相似度或成功率。弱命中可能只有量測項目相同，需核對產品用途。

每筆顯示原始實驗連結、日期、命中原因、範本欄位、組別條件、操作步驟與既有結果／評分。選擇參照實驗時列出範本、配方、組數、條件與步驟差異。包含既有染整欄位及通用 JSON 條件；目前為參考，沒有自動複製／儲存按鈕。

## 結果比較

選擇最近100筆中的1至8筆實驗。先顯示來源量測值、結果說明、組別設計條件差異與缺漏。scoreItems.actualValue 是實測值；confirmedValue、standardValue、條件設定及預設 isSuccess 不代替量測值或失敗結論。評分另外以「評分」標示。缺值、非數字、重複項目排除並提醒，零是有效值。

核對同名項目的量測方法、單位與評分尺度一致後，可計算 n、平均、最小／最大及樣本標準差。時間差值為不同日期最早與最晚已記錄值之差，不是預測趨勢；同日不計時間差。四筆以上以線性插值四分位數及1.5倍 IQR 標記異常候選，不刪除紀錄，不證明因果或合格。不同實驗不一定是獨立重複。

目前資料模型只儲存實驗層級結果，沒有每組獨立量測。介面會明確分開各組設計設定和實驗層級結果，不能計算各組實測差異。

計算立即產生可編輯摘要；可複製供使用者整理，尚不寫回結果。可額外按「本機 AI 整理重點」：最多等待15秒、不重試，Qwen只選取已產生事實的ID。最終文字全部來自已計算與驗證的事實，模型自由生成的數字／答案不使用。失敗則保留完整計算摘要。此功能沒有把資料送至雲端。

新增測試涵蓋數值來源、零與缺漏、重複項目、可比性、樣本統計、IQR、來源差異、模型輸出白名單、loopback端點、未登入／權限不足、非法ID及缺失記錄。資料庫查詢使用替身，不寫入測試資料。
